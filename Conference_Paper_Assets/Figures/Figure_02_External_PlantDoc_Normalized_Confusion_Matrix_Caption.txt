Figure 2. Row-normalized confusion matrix for the frozen Improved ConvNeXt-Tiny model evaluated zero-shot on the independent PlantDoc external test set (n = 79). PlantDoc contained eight classes mapped to the corresponding PlantVillage labels, while the frozen classifier retained its original 10-class output space. External accuracy was 37.97%, Macro F1 was 30.10%, and balanced accuracy was 34.90%. The matrix demonstrates substantial class-dependent degradation under cross-dataset evaluation. No PlantDoc fine-tuning, threshold optimization, probability calibration fitting, or external-test-driven model selection was performed.
